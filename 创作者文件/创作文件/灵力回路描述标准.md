# 灵力回路描述标准

每条回路描述按四个维度顺序展开。

---

## 一、四维模型

| 维度 | 回答的问题 | 位置 |
|------|-----------|------|
| **触发** | 回路如何启动？ | 句首 |
| **形态** | 回路以什么形式存在？ | 紧接触发 |
| **产出** | 回路产生什么效果？ | 句中 |
| **边界** | 何时停止？代价是什么？ | 句末 |

---

## 二、触发句式

### 主动激活

绝大多数回路的标准触发方式。

```
激活回路时，[回路形态与动作]。
```

> 静流·灵刃绯月：`激活回路时，将灵力凝结为约90cm深红刀刃，割伤处留下灼烧痕迹，对恶灵有特效攻击。刀刃持续消耗灵力，回路关闭或灵力耗尽时消散。`
>
> 天·灭烬：`激活回路时，从小臂铠甲和拳锋生长白色棘刺。棘刺初始强度一般、颜色浅白。每次被击碎或折断后再生，硬度递增，颜色从根部向外逐渐变黑。完全变黑后达到钢铁般的硬度与锐利度。棘刺仅存在于回路激活期间，回路关闭或灵力耗尽时棘刺消散。`

### 条件触发

回路并非主观激活，而是由外部条件触发。

```
[条件]时回路自动激活，[回路形态与动作]。
```

> 奏·消力：`受力时回路自动激活，释放灵力护层吸收冲击，并在反击时释放吸收的冲击力。吸收量受灵力上限约束，超出部分直接穿透。`

### 接触触发

回路通过身体接触他人触发。

```
皮肤接触时回路自动激活，[回路形态与动作]。
```

> 迟·蚀骨：`皮肤接触时回路自动激活，建立双向灵力链接，同步感知反馈以实时校准，以痛苦或快感淹没目标的灵力回路。链接持续消耗灵力，接触中断或回路关闭时链接解除。`

### 身体损伤触发

回路通过自伤行为激活。

```
[身体损伤方式]时回路自动激活，[回路形态与动作]。
```

> 红·猩红迷雾：`割开皮肤时回路自动激活，释放血雾，雾域延伸自循环系统，随心跳搏动。雾中可瞬间转移、以血液构筑锋刃与弹药、获得全方位感知。血与灵力在雾中双向转化，伤口闭合或灵力耗尽时消散。`

### 特殊触发

非标准触发方式，用于特殊回路类型。

> 弦音·弦音：`发声时回路同步激活，灵力通过声带振动输出为探测波，触及物体后返回其内部共振特征。可识别裂纹、松动与结构弱点。距离越远、材质越密，返回信号越模糊。`
>
> 克羽·故事集：`触摸痕迹或物件时回路自动激活，以灵力将其记忆数据构建为视觉信息层。根据线索逐层解锁：第一层回顾追踪轨迹，第二层前瞻三十秒第一人称视角，第三层完整时间线回放。不可跳层，每层解锁消耗灵力，回路关闭或灵力耗尽时信息层消散。`

### 被动常驻

回路无需激活，持续运转。省略触发词，以回路形态开头。

> 零·余烬：`激活回路时，将血肉与灰烬相互转化。可将自身转化为灰烬构筑武器或塑造构造物。自身或构造物接触携带灵力之物时，将其转化为灰烬并吸收，以此维持崩坏的身体。回路持续运转，关闭后灰烬产物消散。`

## 三、边界句式

边界描述必须独立成句，不可省略。

### 构筑物/形态型

产物随回路状态消失。

```
回路关闭或灵力耗尽时[产物名称]消散。
```

适用于：刀刃、冰甲、棘刺、玫瑰武器、灵体分身、钢翼、血雾、共鸣场、雾霭、屏障等。

### 持续性效果

效果本身持续消耗灵力。

```
[效果描述]。持续消耗灵力。
```

或：

```
[效果描述]，持续消耗灵力。
```

### 接触依赖型

效果依赖物理接触维持。

```
接触中断或回路关闭时链接解除。
```

### 次数硬上限

明确最大使用次数。

```
至多X次，灵力耗尽前可重复使用。
```

> 菲利普·瞬闪：`激活回路时，将灵力注入双腿实现近乎瞬间的冲刺，每次5m。灵力耗尽前至多连续四次。`

或：

```
每日至多X发。
```

> 布雷德·龙息：`激活回路时，将炽热灵力集中在一点进行喷射释放。裸放两至三次即耗尽灵力储备。也可将龙息预先注入特制霰弹枪弹壳，每日至多六发。`

### 精度/范围衰减

效果随物理变量递减。

```
[精度/范围]随[变量]衰减。
```

> 铃·微视：`激活回路时获得显微级灵力回路感知能力，可在针尖、别针等亚厘米表面雕刻灵力回路。精度随尺度增大而下降，5cm以下为最佳工作范围。回路持续消耗灵力。`
>
> 弦音·弦音：`距离越远、材质越密，返回信号越模糊。`

## 四、形态动词

按回路产出物类别固定动词。

| 产出物类别 | 动词 | 示例回路 |
|-----------|------|----------|
| 能量态构筑物 | `凝结` | 灵力针、灵刃绯月、牵丝、绽放（子弹）、遥远的理想城（屏障）、狩灵箭雨（分裂箭矢） |
| 复合结构 | `构筑` | 灭烬（棘刺）、一人成军（灵体分身）、钢翼、玫瑰（三支武器）、命运的织机、掌灯人（提灯） |
| 场域 | `展开` | 猩红迷雾（血雾）、驱疫（领域）、死疫（领域）、胧月（雾霭）、铃音（共鸣场）、死寂（灵力场）、磁流（定向灵力场） |
| 能量射流 | `释放` | 龙息、消力（护层）、弦音（探测波）、气合（灵力薄层） |
| 链接/锚定 | `建立` | 蚀骨（双向链接）、时泊之锚（空间锚定）、链接仓储（空间锚定）、神备（灵力链接）、御灵（双向沟通） |
| 形态变化 | `覆盖` | 潜渊（黑色灵力覆盖自身） |
| 注入 | `注入` | 瞬闪（双腿）、矢志之念（箭矢）、花舞（灵力注入花瓣） |

## 五、句读规则

| 规则 | 用法 |
|------|------|
| 触发短语后 | `，` |
| 同一维度内多项动作 | `、` |
| 不同维度之间 | `。` |
| 分支技法 | `：` 引出，`；` 并联 |
| 回路值结尾 | `。` |

---

## 六、禁令

1. **不写诗意化效果**。`四个人的声音变成了一道` → 写回路产生的物理/灵能变化，如 `多人的音轨被编织为单一合成波形`
2. **不写第三人称叙事**。`她唱和声时` `当保护性的决心凝结时` → 写回路自身的触发条件和机制
3. **不重复 basic_abilities**。灵力储备量、灵视范围等级已在 basic_abilities 中声明，回路中仅写消耗/边界，不写 `以他孱弱的灵力储备` 等重复性描述

---

## 七、花坂血统

花坂血统（薰、千乐）非灵力回路，使用独立格式：

```
无灵力或灵视，可以肉眼观察灵体，以肉体直接攻击灵体，身体机能人类顶峰。
```

不适用本标准的四维模型。

---

## 八、无回路角色

装备增幅型角色（如响）无 `char_special_abilities` 字段。不设空 `{}`。

---

## 九、异常实体

沃拉瑟斯、第一次扭曲等异常实体使用非标字段名，其能力描述不受本标准约束。
