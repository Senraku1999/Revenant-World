# Overview 描述标准

---

## 一、核心原则

Overview 是 AI 建立角色印象的**第一入口**。一句话回答：**什么人、什么身份、什么特点**。

Token 预算：**[0, 60]**。

---

## 二、句式模板

### 身份 + 特征（标准式，大多数角色）

```
[身份/角色]，[核心特征或故事钩子]。
```

> 千子：`情报搜集员与间谍，机智敏锐。`
>
> 千乐：`万事屋店长，花坂家次子，从寻猫到狩灵协会的委托都接，散漫而敏锐。`

### 能力 + 身份（战斗向角色）

```
[核心能力/打法]，[身份或定位]。
```

> 天：`棘刺越碎越硬的近身格斗者。护短，藏不住事。`
>
> 奏：`资深战斗考官，以不可突破的防御甄别狩灵资质。`

### 组织角色 + 个人贡献（四色音式）

```
[组织名]的[角色]，[独特贡献或描述]。
```

> 花音：`四色音的和声担当，舞台上每一套演出服都是她一针一线做的。`
>
> 铃音：`四色音的作曲和制作人，写 beat、切音轨，并且不肯承认自己是四色音里最好的。`

---

## 三、可写与不可写

### 可写

| 类别 | 示例 | 说明 |
|------|------|------|
| 身份/角色 | `万事屋店长` `情报搜集员` `狩灵协会2科副科长` | 当前角色定位 |
| 核心特征 | `散漫而敏锐` `以不可突破的防御` | 一句话概括 |
| 故事钩子 | `从寻猫到狩灵协会的委托都接` | 给出对话起点 |
| 前组织身份 | `前狩灵协会2科成员` | 仅当角色已离开该组织时写 |

### 不可写

| 类别 | 示例（违规） | 原因 |
|------|-------------|------|
| 现任组织复述 | `狩灵协会成员` | 已在 `char_faction` + `char_status` 中声明 |
| 纯 origin 压缩 | `童年觉醒御灵后拒绝将能力投入正面战斗...` | origin 字段负责经历，overview 负责"现在是谁" |
| 纯性格描述 | `忠实完成每一项任务，很少流露情感。` | 不写身份，读者不知道这个人做什么 |
| 分号 `；` | `救愿意活下去的人；给失去求生意志的人一个庄严的死亡。` | `；` 仅限并列枚举，不用于句子连接 |
| 文学化比喻 | `花坂家的心脏，以一人之力凝聚着...` | overview 是事实性入口，非散文段落 |
| 英语单词混入 | `写 beat、切音轨` | 术语可保留但应以中文为主 |

---

## 四、句式规则

- 结尾 `。`
- 以一句为主，需要时可用两句
- 逗号分隔语义单元，不用分号
- 不写 `char_faction` 和 `char_status` 已声明的现任组织名

---

## 五、正误对照

| 违规 | 合规 |
|------|------|
| `忠实完成每一项任务，很少流露情感。` | `晨昏事务所执行者，忠实完成每一项任务，很少流露情感。` |
| `懒散外表下藏着敏锐判断与狂战士本能。` | `狩灵协会2科科长，懒散外表下藏着敏锐判断与狂战士本能。` |
| `童年觉醒御灵后拒绝将能力投入正面战斗，以与动物的沟通和滋养能力承接寻物、追踪等日常委托。` | `以与动物的沟通和滋养能力承接寻物、追踪等日常委托，拒绝将能力投入正面战斗。` |
| `救愿意活下去的人；给失去求生意志的人一个庄严的死亡。` | `狩灵协会5科医疗狩灵。救愿意活下去的人，给失去求生意志的人一个庄严的死亡。` |
| `十八岁从东大毕业，拒绝正式狩灵道路，按自己的节奏发挥才华。` | `天才狩灵，拒绝协会的正统路线，按自己的节奏接委托。` |

---

## 六、特殊案例

- **时间线变体**（如菲利普·钢翼）：可将事件锚点写入 overview 作为分版本标识
- **双重人格**：可在 overview 中声明人格结构（如 `明/月`）
- **异常实体**：使用 `form` 字段描述外观，overview 用于说明本质
