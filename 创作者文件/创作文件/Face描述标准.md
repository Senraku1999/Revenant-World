# Face 描述标准

基于全项目 52 张角色卡的实际写法归纳。

---

## 一、模板

Face 仅描述**在任何时刻看这张脸都能看到的固定物理特征**。

### 标准式（最常用）

```
[X]色眼睛。
```

> `蓝色眼睛。`
>
> `浅绿色眼睛。`

### 带标记式（使用条件：角色有永久性面部标记）

```
[X]色眼睛，[标记]。
```

> `淡灰色眼睛，眼下挂着浓重的黑眼圈。`
>
> `深灰色眼睛，左眼角一道细疤。`
>
> `酒红色眼睛，眼下挂着淡淡黑眼圈。`

### 肤色优先式（使用条件：肤色本身是辨识特征）

```
肤色[偏白/苍白]，[X]色眼睛。
```

> `肤色偏白，碧色眼睛。`

## 二、固定用词

### 瞳色格式

固定格式 `[颜色]色眼睛`。全项目实际使用的颜色：

固定格式 `[颜色]色眼睛`。全项目实际使用的颜色：

`蓝色` `深蓝色` `亮蓝色` `碧色` `棕色` `深棕色` `浅褐色` `琥珀色` `灰色` `深灰色` `淡灰色` `黑色` `金色` `绿色` `深绿色` `浅绿色` `红色` `紫色` `粉色` `黄色` `酒红色`

### 标记用词

全项目实际使用的标记类型：

| 类别 | 固定措辞 | 使用角色 |
|------|----------|------|
| 眼镜 | `银色细框眼镜` | 君房 |
| 黑眼圈 | `眼下挂着[浓重的/明显的/淡淡的]黑眼圈` | 巴拉尔、克羽、世 |
| 青灰眼底 | `眼下有淡淡的青灰色` | 斯瓦尔 |
| 细疤 | `左眼角一道细疤` | 静流 |
| 纵贯伤疤 | `纵贯眼睛的伤疤` | 慎 |
| 面部伤疤 | `脸上残留着过往战斗的伤疤` | 劫 |
| 眼尾细纹 | `眼尾细纹` | 伊予 |
| 眉心竖痕 | `眉心一道常年皱眉留下的竖痕` | 炼司 |
| 习惯性微蹙 | `眉间习惯性微蹙` | 铃音 |
| 眼型狭长 | `眼型狭长` | 弦音 |
| 半垂眼睑 | `半垂着眼` | 红 |
| 习惯性眯眼 | `习惯性地眯起聚焦` | 铃 |

眼镜写在瞳色之后：`[X]色眼睛，[材质/款式]眼镜。`

### 禁止写入

| 类别 | 示例 |
|------|------|
| 气质形容词 | `温和的面容` `面容清冷` `面容冷峻` `柔和的面容` |
| 一次性表情 | `表情冷硬` `神采奕奕` `目光涣散` |
| 化妆 | `涂着红色唇膏` |
| 年龄评价 | `年轻的面容`（随时间变化） |

---

## 三、句式规则

- 结尾 `。`
- 要素间 `，` 分隔
- 瞳色格式固定为 `X色眼睛`，不可省略 `色` 或 `眼睛`
- 标记统一用 `挂着`（黑眼圈）、`一道`（细疤）、`残留着`（多处旧伤）

---

## 四、特殊案例

- **面部被遮盖**（零）：描述可见部分，不受模板约束。`面部缠满灰白色绷带，未见明显五官。`
- **异常实体**：使用 `form` 字段，不适用本标准。
