# Clothing 描述标准

基于全项目 52 张角色卡的实际写法归纳。

---

## 一、模板

Clothing 描述角色日常穿着的固定服装。

### 标准式（70% 角色使用）

```
[上装内搭]，[上装外搭]，[下装]，[鞋类]。
```

> `白色衬衫，灰色马甲，黑色燕尾服，黑色长裤，黑色皮鞋。`
>
> `米白衬衫，卡其色夹克，棕色格纹短裙，棕色皮鞋。`

### 带袜式（袜类在鞋类之前）

```
[上装]，[下装]，[袜类]，[鞋类]。
```

> `棕色T恤，米色针织开衫，百褶长裙，灰色棉袜，制服鞋。`
>
> `米白色七分袖针织衫，卡其色高腰A字裙，白色丝袜，棕色低跟乐福鞋。`

### 带配饰式（配饰在句号后独立成句）

```
[主体链]。[配饰描述]。
```

> `黑色衬衫，白色实验服，休闲裤，作战靴。眼镜。`
>
> `白色衬衫，黑色领带，棕色工装马甲，白色长裤，黑色军靴。右耳戴一枚金色翼形耳环。`

### 链内配饰式（配饰并入逗号链，配饰量多时使用）

```
[主体链]，[配饰]，[配饰]。
```

> `白色短袖衬衫，绿色战术背心，浅棕色短裙，过膝长靴。黑色项圈，黑色背带，棕色胸章，黑色战术臂甲，腿甲。`

### 制服共享式（同一组织共用模板）

四色音基础模板：
```
改良水手领无袖上衣，百褶短裙，黑色过膝袜，黑色厚底短靴，[角色色]腕带与颈链。
```

各成员仅颜色和单件差异化：
- 弦音：`领口系蓝色蝴蝶结。`
- 花音：`裙摆右侧加了一层不对称小拖尾。`
- 铃音：`腰间系一条金色细链。`
- 心音：`左臂系一条红色飘带。`

### 锈钟胸针式（指针/齿轮角色）

```
[主体链]。[材质][职位]胸针别在[位置]。
```

> `灰色高领毛衣，黑色长裤，平底皮鞋。金质时针胸针别在领口。`
>
> `白色衬衫，灰色外套系在腰间，黑色长裤，板鞋。银质分针胸针别在胸前。`

## 二、固定顺序

```
上身(内层 → 外层 → 腰带/束带/领带) → 下身 → 袜类 → 鞋类 → 尾部配饰
```

腰带、束带、领带等腰部配饰位于上身外层与下身之间——这是实际穿衣的物理顺序。装饰性配饰（胸针、耳环、腕带、飘带、项链、手套、护臂等）放在鞋类之后。

单品 2-6 件。配饰可并入逗号链，也可在句号后独立成句。

## 三、固定措辞

### 上装内层（贴身穿）

`T恤` `衬衫` `背心` `毛衣` `高领毛衣` `高领` `针织衫` `紧身衣` `内衬` `紧身休闲服` `紧身背心`

### 上装外层

`外套` `夹克` `马甲` `开衫` `风衣` `西装外套` `燕尾服` `实验服` `工装外套` `皮夹克` `连帽衫` `连帽夹克` `罩衫` `大褂`

### 下装

`长裤` `短裤` `牛仔裤` `西裤` `休闲裤` `工装裤` `阔腿裤` `帆布长裤` `百褶长裙` `迷你裙` `短裙` `包臀裙` `格纹短裙` `高腰A字裙` `旗袍` `袴`

### 鞋类

`皮鞋` `靴子` `短靴` `作战靴` `军靴` `运动鞋` `板鞋` `乐福鞋` `马丁靴` `皮靴` `高跟鞋` `厚底短靴` `长靴` `制服鞋`

### 袜类（在下装与鞋之间）

`丝袜` `过膝袜` `长袜` `棉袜` `短袜`

### 腰部配饰（上身与下身之间）

`腰带` `束带` `领带` `背带` `腰封`

### 尾部配饰（鞋类之后，逗号链内或句号后）

`眼镜` `耳环` `领巾` `围巾` `蝴蝶结` `丝带` `胸针` `项链` `手套` `腕带` `手笼` `项圈` `护臂` `腿甲` `肩甲` `护目镜` `臂甲` `飘带` `细链`

### 锈钟胸针（固定句式）

| 帮派 | 职位 | 胸针句式 |
|------|------|----------|
| 指针-时针 | 时针 | `金质时针胸针别在领口。` |
| 指针-分针 | 分针 | `银质分针胸针别在胸前。` |
| 指针-秒针 | 秒针 | `紫铜秒针胸针别在胸前。` |
| 齿轮 | 各职位 | `小齿轮胸针别在领口/胸口口袋。` |

---

## 四、句式规则

- 全字段一逗到底，仅末尾 `。`
- 单品间 `，` 分隔
- 配饰并入逗号链，不独立成句

---

## 五、禁止写入

| 类别 | 示例 |
|------|------|
| 武器放置 | `后腰佩两柄刺剑。` `右大腿外侧绑霰弹枪皮套。`（归入 weapon 字段） |
| 条件性穿着 | `天冷时加一件风衣。`（只写常态着装） |
