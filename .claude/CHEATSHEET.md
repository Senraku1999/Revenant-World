# 速查表

> 复制引号内文字发送即可。项目经理自动调度。

```
检查          → 增量审查（提交前必做）
提交          → 检查 + 通过后提交
影响          → 从改动自动分析影响面
影响 关键词   → 查特定实体的影响面

CB           → ControlBoundary 审查
CB 全部      → 全项目 CB 扫描
同步          → 中英文 JSON 一致性
同步 角色     → 指定角色 JSON 对比
逻辑 角色     → 开场白六项核查（prose-reviewer）
逻辑 全部     → 全项目开场白核查
逻辑矛盾      → 跨文件逻辑比对（logic-reviewer）
⚠ "逻辑"有两种用法：对单角色=六项核查，说"逻辑矛盾"=跨文件比对

全量          → 版本发布前全量审查
抽样          → 轻量抽样审查（8 角色，全阵营覆盖）
学术 角色     → 五视角并行深度审查
修            → 自动修复最近审查发现的问题
修标点        → 修复标点问题
token 角色    → Token 诊断报告（token-reviewer，仅审查）
修token 角色  → Token 诊断 + 执行压缩

导出          → 按序跑三条导出管线（关系网→世界书→PNG）
```
